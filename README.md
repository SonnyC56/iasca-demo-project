# IASCA Demo Project — CRM

A general-purpose CRM (Customer Relationship Management) application.

## Status

🚧 Planning phase. No features or infrastructure have been built yet — the tech stack,
data model, and feature roadmap are being defined first.

## Planned Core Areas (tentative)

- **Contacts** — people you do business with
- **Companies / Accounts** — organizations contacts belong to
- **Deals / Opportunities** — sales pipeline with stages
- **Activities** — notes, calls, emails, meetings, tasks
- **Users & Auth** — team members, roles, permissions

Details will be finalized in the project plan.
